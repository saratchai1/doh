# คู่มือทดลองใช้ระบบติดตามงาน (UAT)

> สำนักสำรวจและออกแบบ กรมทางหลวง  
> ระบบทดลอง: https://doh-work-tracking-dzcxv4.v2.appdeploy.ai/

## เป้าหมาย

ให้แต่ละคนสร้างงานของตัวเอง 1 เรื่อง แล้วทดลองเดินงานตั้งแต่รับเรื่อง → รส.สบ. → หน่วย → ทำเองหรือส่ง IH → ส่งกลับ → ปิดงาน เพื่อดูว่าระบบตอบได้หรือไม่ว่า **งานอยู่ที่ไหน / อยู่กับใคร / ค้างมากี่วัน / ทำอะไรไปแล้วบ้าง**

## ก่อนเริ่มทดลอง

1. แต่ละคนสร้างงานของตัวเองคนละ 1 เรื่อง เช่น `TEST-SOMCHAI-01`
2. ช่วง UAT สามารถใส่วันที่ย้อนหลังหรือวันที่สมมติได้
3. วันที่ของขั้นตอนใหม่ต้องเท่ากับหรือหลังเหตุการณ์ก่อนหน้า
4. กดบันทึกแล้ว Refresh ได้ ข้อมูลไม่หาย แต่ข้อความที่ยังไม่ได้บันทึกจะหายเมื่อ Refresh
5. สำนักอำนวยความปลอดภัยเป็น **ต้นเรื่อง** ไม่ใช่จุดค้างงานภายใน เมื่อส่งกลับแล้วระบบจะแสดง **ส่งกลับแล้ว / รอยืนยันปิดงาน**

## เริ่มงานใหม่

กด **+ รับเรื่องใหม่** แล้วกรอกเลขที่หนังสือ, ต้นเรื่อง, เรื่อง, ถนน/สถานที่, รส.สบ., หน่วยเจ้าของงาน และวันที่สำนักสำรวจและออกแบบรับงาน จากนั้นกด **สร้าง Work Order**

ตัวอย่าง:
- เลขที่หนังสือ: `TEST-SOMCHAI-01`
- ต้นเรื่อง: สำนักอำนวยความปลอดภัย
- เรื่อง: ขอแก้ไขแบบบริเวณทางแยก
- สถานที่: ทล.1 กม.10+500
- รส.สบ.: รส.สบ.1
- หน่วย: วทบ.2
- วันที่รับงาน: 1 ต.ค. 2569 09:00 น.

## วันที่สมมติใน UAT

ในหน้างานจะมีช่อง **วันที่/เวลาของขั้นตอนถัดไป (UAT)** ให้เลือกก่อนกดรับงาน ส่งงาน ประเมิน กำหนดผู้รับผิดชอบ หรือปิดงาน

ตัวอย่าง:
- 1 ต.ค. 09:00 — สำนักสำรวจและออกแบบรับงาน
- 2 ต.ค. 10:00 — รส.สบ.1 รับเรื่อง
- 3 ต.ค. 11:00 — วทบ.2 รับเรื่อง
- 4 ต.ค. 13:00 — ประเมินระดับ 1
- 7 ต.ค. 15:00 — หน่วยทำเสร็จ
- 8 ต.ค. 09:00 — รส.สบ.1 รับงานกลับ

Production จะล็อกเวลาและใช้เวลาจากระบบอัตโนมัติ ผู้ใช้จะไม่สามารถแก้วันที่เองได้

## กรณีหน่วยทำงานเอง

รส.สบ. รับ → หน่วยรับ → กำหนดผู้รับผิดชอบ → ประเมินระดับ 1 ถึง 4 → ทำงาน → หน่วยทำเสร็จและส่งออก → รส.สบ. รับงานกลับ → ส่งกลับต้นเรื่อง → ปิดงาน

ระดับความยาก:
- ระดับ 1 ง่าย: 7 วัน
- ระดับ 2 ปานกลาง: 21 วัน
- ระดับ 3 ยาก: 30 วัน
- ระดับ 4 ซับซ้อนมาก: 60 วัน

## กรณีส่ง In-house Consultant (IH)

หน่วยรับและประเมิน → ส่งให้ IH → รส.สบ. รับเรื่องเพื่อส่ง IH → รส.สบ. ส่งให้ IH → IH รับงานจริง → IH ประเมินใหม่ได้ → IH ทำงานและส่งกลับ → หน่วยตรวจ

ถ้าไม่ผ่านสามารถ **ส่งกลับ IH แก้ไข** รอบ 2, 3, ... ได้ โดย Timeline เดิมไม่หาย

## อ่าน Dashboard

ทุกงานควรตอบได้:
- **WHERE** — ตอนนี้อยู่ที่ไหน
- **WHO** — อยู่กับใคร
- **SINCE** — อยู่ที่นี่ตั้งแต่เมื่อไร
- **AGE** — ค้างกี่วัน
- **DUE** — ต้องเสร็จเมื่อไร
- **NEXT** — ต้องทำอะไรต่อ

**Executive Attention Queue** จะดันงานที่ควรติดตามก่อน เช่น เกินกำหนด ค้างนาน หรือ Due ใกล้ถึง

## ปัญหาที่พบบ่อย

- **Refresh แล้วข้อมูลหายไหม?** กดบันทึกแล้วไม่หาย
- **กดขั้นตอนต่อไปไม่ได้?** ตรวจวันที่ UAT และลำดับขั้นตอน
- **ชื่อผู้รับผิดชอบหายหลังส่งไปหน่วยอื่น?** ต้องกำหนด WHO ใหม่เมื่อเปลี่ยนผู้ถือเรื่อง
- **10 คนใช้พร้อมกันได้ไหม?** สำหรับ UAT คนละ Work Order ได้ ควรหลีกเลี่ยง 2 คนแก้งานเดียวกันพร้อมกัน
- **ส่งกลับสำนักอำนวยความปลอดภัยแล้วทำไมไม่ขึ้นว่าค้าง?** ถูกต้อง เพราะเป็นต้นเรื่อง/ปลายทาง ไม่ใช่คิวดำเนินงานภายใน

3. กดอะไรแล้วเกิดปัญหา
